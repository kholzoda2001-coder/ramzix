# RamzIx — нақшаи лоиҳа

Платформаи онлайни **B2B (оптовӣ) + B2C (чакана)** барои таъмини мағозаҳо, ширкатҳо ва фурӯшандагон бо маҳсулот аз **Аморат (Дубай), Чин, Туркия** ва **Тоҷикистон**.

## 1. Модели фурӯш: оптом ҳам, дона ҳам

**Тавсия: ҳарду, вале бо як маҳсулот ва нархи зинагӣ** (на ду сайти ҷудо).

| Зина | Миқдор | Нарх | Кӣ мебинад |
|---|---|---|---|
| Чакана | 1–3 дона | нархи оддӣ | ҳама |
| Хурдоптом | 4–9 дона | то −8% | ҳама |
| Оптовӣ | 10–99 дона | то −20% | ҳама (ё танҳо ҳисоби бизнес, ихтиёрӣ) |
| Калон | 100+ дона | бо дархост (RFQ) | менеҷер ҷавоб медиҳад |

Чаро:
- Мизоҷи чакана трафик ва бренд меорад, мағоза фоидаи асосиро.
- Мағозаҳои хурд аввал 1–4 дона месанҷанд, баъд калон мегиранд.
- Нарх худкор аз рӯи миқдор тағйир меёбад (дар саҳифаи маҳсулот кор мекунад).
- Барои ҳар маҳсулот **MOQ** (ҳадди ақал) алоҳида танзим мешавад: баъзе маҳсулот (масалан лампа) танҳо оптом фурӯхта мешаванд.

## 2. Намудҳои истифодабаранда

1. **Меҳмон / харидори чакана**: мебинад, мехарад, пардохт мекунад.
2. **Ҳисоби бизнес (B2B)**: ИНН / шаҳодатнома, нархҳои махсус, фактура, пардохт бо мӯҳлат, менеҷери шахсӣ.
3. **Таъминкунанда (vendor)**: дар Дубай, Чин, Туркия ё ватанӣ; маҳсулот ва нархҳои зинагиро бор мекунад.
4. **Админ / менеҷер**: тасдиқи фармоиш, RFQ, логистика, қурби асъор.

## 4. Чизҳои махсус барои минтақа

- **Асъор:** асосӣ сомонӣ (TJS), интихоби USD; қурб ҳар рӯз навсозӣ мешавад.
- **Забон:** тоҷикӣ, русӣ, англисӣ.
- **Пардохт:** Алиф, DC (Душанбе Сити), Эсхата, Visa/MC, интиқоли бонкӣ барои ширкатҳо, нақд ҳангоми гирифтан.
- **Расонидан:** аз анбори Душанбе 1–3 рӯз; аз Дубай 7–25 рӯз (авиа ё автомобил), аз Чин/Туркия 15–30 рӯз; гумрук дар нарх ё алоҳида.
- **Алоқа:** WhatsApp ва Telegram дар ҳар саҳифа.
- **Мобайл аввал:** аксари мизоҷон аз телефон медароянд.

## 5. Технология (пешниҳод)

Фронтенд: **Next.js** (дар ҳамин папка). Барои backend (фармоиш, ҳисобҳо, панели админ) бояд интихоб шавад: API-и худ ё платформаи тайёр.

## 6. Саволҳо барои соҳиби лоиҳа

1. Оё нархи оптовӣ ба ҳама намоён бошад ё танҳо ба ҳисоби бизнеси тасдиқшуда?
2. Анбор дар Душанбе ҳаст ё ҳамаи мол аз хориҷ фармоиш дода мешавад?
3. Таъминкунандагони дигар (multi-vendor) худашон мол бор мекунанд ё танҳо шумо?
4. Ба ғайр аз Тоҷикистон ба кадом кишварҳо мефурӯшед (Ӯзбекистон, Қирғизистон, Русия)?
5. Номи ниҳоӣ ва ранг: **RamzIx** (кабуди торик + норинҷӣ) ё **RamzB2B** (кабуд + тиллоӣ)?
6. Backend: API-и худамон ё платформаи тайёр?
