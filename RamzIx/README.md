# RamzIx

Платформаи онлайни фурӯши оптовӣ ва чакана: таъмини мағозаҳо бо маҳсулот аз Аморат, Чин, Туркия ва Тоҷикистон.

- `PLAN.md` — нақша, модели фурӯш ва саволҳо
- `design/index.html` — дизайни саҳифаи асосӣ
- `design/product.html` — дизайни саҳифаи маҳсулот

Барои дидан `design/index.html`-ро дар браузер кушоед.
